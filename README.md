# 🚀 NEXT_JS_CLASS_2

A practical **Next.js learning project** created to understand and practice important concepts beyond the basics.

## 📚 Topics Covered

* 🔗 Link & Navigation
* 🧭 `useRouter`
* 🧩 `useParams`
* 🛣️ Dynamic Routes
* 💻 Client Components
* 📝 Forms & Form Handling
* 🔄 `onChange` Events
* 📦 Components & Props
* 📡 Data Fetching
* 🎯 Conditional Rendering

## 🛠️ Tech Stack

* Next.js
* JavaScript
* React
* CSS
* npm

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/CodeWIthAbdullah-007/NEXT_JS_CLASS_2.git
```

Move into the project:

```bash
cd NEXT_JS_CLASS_2
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

This project is part of my **Next.js learning journey**. It focuses on practical implementation of routing, navigation, dynamic pages, client-side functionality, and form handling.
